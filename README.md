# Inbreker Detector 7000

The **Inbreker Detector 7000 (ID 7000)** is a security system powered by the Raspberry Pi 2B and built with our custom **SecureWatch OS**.  
It is designed to be fast, reliable, and always connected, combining multiple hardware layers into one cohesive protection system.

## 🚨 Features

### 🔒 SecureWatch OS
A custom operating system optimized for speed, stability, and security.

### 📡 Remote Access
Control the alarm system over WiFi using an ESP32-based controller.

### 🧩 Three‑Layer Architecture
- **Arduino sensors** — detect motion and environmental triggers  
- **Raspberry Pi brain** — processes data and runs SecureWatch OS  
- **ESP32 interface** — handles wireless communication and remote control  

## 🖥 Demo
A live demo is available through the website interface.

## 🛠 Technology Stack
- Raspberry Pi 2B  
- Arduino sensor modules  
- ESP32 WiFi controller  
- SecureWatch OS (custom‑built)
